# Hanpangan - Aplikasi Jadwal Piket Koramil 1609-05/Sukasada

Aplikasi PWA untuk manajemen jadwal piket dan laporan hanpangan.

## 🌐 Live Demo

- **GitHub Pages:** https://sukasada05.github.io/Hanpangan/
- **Cloudflare Worker:** https://jadwalpkt.dukopbabinsa05.workers.dev/

## 📋 Fitur

- ✅ Jadwal piket harian (Koramil, Kediaman, Makodim)
- ✅ Data Hanpangan (Petugas Pangan)
- ✅ Kirim ke WhatsApp & Telegram (1 tombol)
- ✅ Cetak PDF jadwal bulanan
- ✅ Auto-save ke Supabase
- ✅ PWA (bisa diinstall di HP)
- ✅ Trigger otomatis 08.00 WITA

## 🔧 Teknologi

- Cloudflare Worker (Backend)
- Supabase (Database)
- GitHub Pages (Frontend)
- Service Worker (PWA)
